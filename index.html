Cotizaciones

Es un documento que usted envía a un cliente para informarle cuánto costará un trabajo.

  • Qué incluye: Materiales, mano de obra, flete e impuestos.
  • Para qué sirve: Para que el cliente apruebe el presupuesto antes de comenzar.
  • Qué puede hacer: Generar PDF, enviar por email, asociar órdenes de servicio.
Ejemplo: "Cotización para reparación de techo: $1.200.000 (materiales + mano de obra)"
🎫

Órdenes de Servicio

Es el registro de un trabajo que usted o su equipo deben realizar para un cliente.

  • Qué incluye: Descripción del trabajo, fechas, usuarios asignados.
  • Para qué sirve: Para organizar y dar seguimiento a cada tarea.
  • Qué puede hacer: Asignar personal, adjuntar fotos, generar informes PDF.
Ejemplo: "Orden de servicio #102 - Inspección de instalación eléctrica - Juan Pérez (técnico)"
📑

Contratos

Es un acuerdo formal con un cliente para brindar servicios de manera regular.

  • Qué incluye: Plan de atención, fechas, cotizaciones asociadas.
  • Para qué sirve: Para tener clientes recurrentes y trabajo asegurado.
  • Qué puede hacer: Agrupar órdenes de servicio, ver historial completo.
Ejemplo: "Contrato de mantenimiento anual - Edificio Central - 12 visitas mensuales"

Cómo se relacionan

📄Cotización→🎫Orden de Servicio→📑Contrato

Una cotización puede llevar a una orden de servicio, y varias órdenes pueden agruparse en un contrato.
